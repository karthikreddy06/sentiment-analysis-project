About Sentiment AI

Sentiment AI is a machine‑learning powered application designed to analyze the emotional tone of text. It helps users quickly understand whether a piece of text expresses a positive, negative, or neutral sentiment.

The service runs a state‑of‑the‑art transformer model locally, ensuring fast, private, and reliable predictions without sending data to external APIs unless you explicitly enable the Watson provider.

Getting started and API reference.

Getting Started

  1. Enter text in the analyzer above.
  2. Click Analyze Sentiment.
  3. Wait for the AI model to process the text.
  4. Review the predicted sentiment (Positive, Negative, Neutral).
  5. Review the confidence score.

Supported Sentiment Labels

  • Positive – expresses happiness, approval, satisfaction.
  • Negative – expresses dissatisfaction, anger, sadness.
  • Neutral – objective or no strong emotional tone.

API Usage

Send a POST request to /sentimentAnalyzer with JSON body:

POST /sentimentAnalyzer
Content-Type: application/json

{
  "text": "I love this product!"
}

Successful response:

{
  "success": true,
  "label": "POSITIVE",
  "score": 0.9873,
  "provider": "local",
  "message": "The given text has been identified as POSITIVE with a score of 0.9873."
}

Error Handling

The API returns appropriate HTTP status codes:

  • 400 – Invalid or empty input.
  • 503 – Service unavailable (model load failure or external provider timeout).

Help Center

Frequently asked questions.

How does sentiment analysis work?

Our model uses a transformer‑based neural network trained on large text corpora to classify the emotional tone of the input text.

What does Positive mean?

The text expresses happiness, approval, satisfaction, or other positive feelings.

What does Negative mean?

The text expresses dissatisfaction, anger, sadness, or other negative feelings.

What does Neutral mean?

The text is objective, factual, or does not convey a strong emotional tone.

What does the confidence score represent?

It is the model’s probability (0‑1) for the predicted label, shown as a percentage.

Why might analysis fail?

Empty input, text longer than 2000 characters, or temporary model loading issues can cause errors.

Is my text stored?

No. All analysis happens in memory; no data is persisted or sent to third parties unless you enable the Watson provider.
